# Тайный Санта — онлайн

## Запуск
Нужен Node.js 18+ (без npm-пакетов). В папке проекта: `node server.js`. Откройте http://localhost:3000.

## Публикация
Разместите приложение на сервере с Node.js и HTTPS, задайте переменную `PORT` (если нужна) и подключите постоянный диск для `games.json` либо задайте `DATA_FILE=/путь/на/постоянном/диске/games.json`. На хостинге без постоянного диска жеребьёвки пропадут при перезапуске/деплое. Используйте один экземпляр сервера: JSON-файл не рассчитан на конкурентную запись несколькими процессами.

## Секретность
Организатору показываются только персональные ссылки, не пары. Получатель видит свою пару по секретной ссылке. Тот, у кого есть чужая ссылка, может увидеть чужой результат. Администратор сервера, имеющий доступ к файлу `games.json`, технически может увидеть все пары: это не end-to-end шифрование. Не публикуйте `games.json` и не отправляйте всем участникам общий список ссылок. Ссылки нельзя восстановить через интерфейс после закрытия страницы.

## Ограничения
Минимум 3 участника. Участник не может выпасть самому себе. Нельзя добавлять исключения пар или пересоздать существующую жеребьёвку. Для серьёзной публичной нагрузки потребуются база данных, rate limiting и контроль доступа.
